## The goal of this document

I want people to be able to read through this document and then be able to start contributing to the Syndicate Campaign in a way that they want that is also hopefully cohesive with this vision. Why should I get to direct the vision for the Syndicate Campaign? Well, if you want to start from scratch you can. I did talk to some actual devs about my ideas when I first started working on this so I had at least a veneer of approval.

## The story (of the SC) so far
- Some time ago (looks like 7 years ago), Derpy started work on the Syndicate campaign [ https://github.com/Amazinite/ES-Syndicate-Campaign ]

- In March of 2025 I got interested in writing for ES, and looked around for any previous work that had been done. I found Derpy’s work on github and started my initial work trying to write similar missions myself. I also started thinking about what should be in the campaign.

- What did it mean to work for the Syndicate? 
 
  - Would First Last join officially or operate more as an independent contractor? 
  
  - How would either choice limit or create opportunities?
  
 - Would First Last join them and rise through the ranks like they do in FW?
 
 - What would be different in terms of benefits to the player?
 
 - How much would FL learn about the Syndicate conspiracy? 
 
 - What are the major decisions that could be made by FL in the story?
 
 - What types of missions and jobs might be available to someone working for the Syndicate?
 
- I wrote up my ideas on a google spreadsheet (which is either here as a downloadable Excel file [ https://github.com/ciridae1/Synicate_campaign_collaboration/blob/48aa0e39815e31d62d5fc8b9b1f9f526bf49a28f/Syndicate%20Campaign%20notes_ideas.xlsx ] or a view only GoogleSheet [ https://docs.google.com/spreadsheets/d/1dU0zUaPBh_mUoUn525stCdMEkxihL3rKFQghHgpIt1M/edit?usp=sharing ]

- I think the main thing here is that I tried to break down what happens in the FW campaign into ‘themes’ or time periods (like the several scouting missions FL is asked to do) and how many of those missions there are (see column I– I didn’t quite finish this process but the first several rows detail what I was thinking about)
