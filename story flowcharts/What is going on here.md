
# What are these files bro?
 
 When I started work on the Syndicate Campaign, I wanted to be able to map out what was going to happen in a way that I could get progressively more and more detailed without having to reformat whatever document or file I was working on over and over. So I found this free flowchart editor and used that. That is why the files look the way they do. The editor is available on github (really hoping other people looking at it isn't how I find out it's malware xD) and is linked below
 https://github.com/jgraph/drawio-desktop/releases/tag/v32.6.10
